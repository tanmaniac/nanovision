# A6 — Flow matching & rectified flow: research validation

## 1. Key concepts a student must learn

### Continuous normalizing flows (CNF)

A CNF defines a generative model through an ODE: `dx/dt = v_t(x; θ)`, where the velocity field `v_t` is a neural network. The flow transports samples from a simple prior `p_0` (e.g., standard Gaussian) to the data distribution `p_1` by integrating the ODE forward. Chen et al. (2018) showed you can train CNFs by maximum likelihood via the instantaneous change-of-variables formula, but this required simulating the ODE during training, making it expensive and unstable at scale.

### The flow matching (FM) objective

Lipman et al. (2022) proposed bypassing ODE simulation entirely by directly regressing the velocity field. The marginal velocity field that generates any probability path `p_t` is intractable in general, but it can be decomposed into conditional probability paths conditioned on a single data point `x_1`:

```
p_t(x) = ∫ p_t(x | x_1) q(x_1) dx_1
u_t(x) = ∫ u_t(x | x_1) [p_t(x | x_1) q(x_1) / p_t(x)] dx_1
```

The **conditional flow matching (CFM) objective** directly regresses onto `u_t(x | x_1)` for a sampled `x_1`:

```
L_CFM(θ) = E_{t, q(x_1), p_t(x|x_1)} [ || v_θ(x, t) - u_t(x | x_1) ||^2 ]
```

This objective has the same gradient as the intractable marginal objective but is fully simulation-free: sample `t ~ U[0,1]`, sample `x_1 ~ q`, sample `x_t` from the conditional path, regress the network onto the known conditional velocity.

### Probability paths and path choices

The conditional path is a distribution `p_t(x | x_1)` that starts at the prior at `t=0` and concentrates on `x_1` at `t=1`. Two canonical choices:

**Linear/affine (Gaussian) path:**
```
x_t = (1-t) x_0 + t x_1,   x_0 ~ N(0, I)
u_t(x | x_1) = x_1 - x_0  (constant, the straight-line velocity)
```

**Variance-preserving (diffusion) path:**
```
x_t = alpha_t x_1 + sigma_t x_0
```
where `alpha_t, sigma_t` follow a noise schedule (cosine, VP-SDE, etc.). Diffusion models are a special case of this family.

### Optimal transport (OT) paths and why they help

With independent coupling `x_0 ~ N(0,I)`, `x_1 ~ q_data`, the marginal velocity field is curved because paths from different `x_1` cross. Using minibatch OT coupling (Tong et al., 2023) pairs each `x_0` with the nearest `x_1` in a mini-batch (via the Hungarian algorithm), making the trajectories straighter. Straighter trajectories require fewer integration steps at inference. This is why FLUX and SD3 both use OT-style linear interpolation rather than diffusion noise schedules.

### Rectified flow

Liu et al. (2022) proposed the same linear interpolation idea independently, naming it **rectified flow**. The key additional contribution is the **reflow procedure**: after training an initial flow model, simulate pairs `(x_0, x_1^hat)` by integrating trajectories forward, then retrain on these new pairs. The 2-rectified flow has straighter trajectories by construction (its training data was generated by following the first model's trajectories). This can be repeated; in practice one reflow step is usually sufficient (Dao et al., 2024). InstaFlow (Liu et al., 2023) demonstrated this on Stable Diffusion-scale models, achieving one-step generation via reflow followed by distillation.

### Why flow matching is simpler than score matching

Score-based diffusion trains a network to estimate `∇_x log p_t(x)` (the score function). This requires knowing the marginal density, which is tractable only for Gaussian forward processes. Flow matching regresses onto a velocity field, which has a tractable conditional target for any path choice, including non-Gaussian ones. The training objective is a plain MSE with an analytic target; there is no Stein identity, no denoising score matching derivation, and no constraint on the forward process family.

### The diffusion-flow equivalence

For Gaussian paths, diffusion and flow matching are the same framework with different parameterizations. Specifically:

- The probability-flow ODE of a VP-SDE diffusion model is identical to the ODE of a flow matching model whose path is `x_t = alpha_t x_1 + sigma_t x_0` with the same schedule.
- The epsilon-prediction, x-prediction, v-prediction, and velocity-field parameterizations are all linear reparameterizations of each other; their MSE losses differ only in time-dependent weighting.
- Flow matching with a cosine noise schedule and v-prediction is algebraically equivalent to standard DDIM sampling.

Where they genuinely differ: (1) rectified flow uses the **linear** schedule `alpha_t = 1-t, sigma_t = t`, which is not variance-preserving; this gives a different effective loss weighting. (2) Flow matching decouples the choice of training path from the choice of sampling ODE/SDE — you can train on a diffusion path but sample with an ODE solver, or vice versa. (3) OT coupling is a purely flow-matching concept; diffusion models always use independent Gaussian noise.

### Logit-normal timestep sampling (SD3)

Uniform sampling of `t` concentrates loss on the extremes (near-noise and near-data), which carry little perceptual information. SD3/Esser et al. (2024) propose sampling `t = sigmoid(z)` where `z ~ N(0, s^2)`, i.e., a logit-normal distribution. This pushes training density toward `t ~ 0.5`, where the model makes the most perceptually meaningful predictions. The mean and scale of the underlying normal are tunable hyperparameters. This is a significant practical detail for getting good results at moderate NFE.

### Few-step sampling

After training, the model is sampled by integrating `dx/dt = v_θ(x, t)` with a standard ODE solver (Euler, RK4, DOPRI5). With straight trajectories, Euler integration with 1-4 steps can match quality that diffusion models need 50-1000 steps to achieve. The key knobs are: (a) trajectory straightness (achieved via OT coupling or reflow), (b) timestep distribution (logit-normal focuses capacity where it matters), (c) solver order.

### Mean flows (2025)

MeanFlow (Geng et al., 2025) extends flow matching by modeling the **time-averaged velocity** (the mean of the velocity over a time interval) rather than the instantaneous velocity. This directly targets what one-step generation needs: the integral `∫ v dt` rather than `v` at a point. The network is trained with a self-consistency constraint that the average velocity from `t=0` to `t=1` equals the displacement. MeanFlow achieves FID 3.43 on ImageNet 256x256 with a single NFE, trained from scratch without distillation or a curriculum. This is currently the strongest one-step flow result.

## 2. What to implement from scratch

### 2a. CFM on a 2D toy distribution (core implementation)

**Problem:** learn to transport `N(0, I)` to a multimodal 2D distribution (e.g., checkerboard, two moons, or 8 Gaussians). Everything is visible: you can plot the vector field at any `(x, t)` and watch trajectories evolve.

**Implementation tasks:**

1. Implement the linear conditional path: `x_t = (1-t)*x_0 + t*x_1`, conditional velocity `u_t = x_1 - x_0`.
2. Write the CFM training loop: sample `t ~ U[0,1]`, sample `(x_0, x_1)` pairs (independent coupling first), compute `x_t`, regress a small MLP onto `u_t`. Loss is just MSE.
3. Implement Euler sampling: integrate `x_{t+dt} = x_t + v_θ(x_t, t) * dt` for `N` steps from `x_0 ~ N(0,I)`.
4. Plot: (a) the learned vector field on a grid at several `t` values, (b) 10-20 sample trajectories overlaid on the data distribution.

**Verifiable tasks:**
- Shape test: `v_θ(x, t)` takes `(B, 2)` + `(B,)` and returns `(B, 2)`.
- `torch.autograd.gradcheck` on the MSE loss.
- Overfit one batch of 256 points to near-zero loss in < 100 steps.
- 10-step Euler sampling produces recognizable multimodal density; 100-step sampling is indistinguishable from data.

### 2b. OT coupling vs. independent coupling (path visualization)

**Problem:** same 2D setup, but compare trajectories under independent Gaussian coupling vs. minibatch OT coupling (use `scipy.optimize.linear_sum_assignment` on pairwise L2 distances within each minibatch).

**Verifiable tasks:**
- Plot trajectories: OT coupling should show visibly straighter lines.
- Measure average trajectory curvature (sum of turn angles along Euler path) — OT should be lower.
- Compare 1-step Euler FID/visual quality between both couplings.

### 2c. Reflow on the 2D toy (rectified flow)

**Problem:** after training the initial flow, simulate 10k `(x_0, x_hat_1)` pairs by running the learned ODE from `x_0 ~ N(0,I)` to `t=1`. Retrain a new model on these pairs with the same CFM objective.

**Verifiable tasks:**
- Plot trajectories of the original model vs. 2-rectified model — the latter should be visibly straighter.
- Show that 1-step Euler from 2-rectified flow produces better samples than 1-step Euler from the original model.
- Measure the "straightness" metric: `E[||x_1 - x_0 - integral v dt||^2]` (how much the flow deviates from a straight line).

### 2d. Reuse the A5 backbone on MNIST/FashionMNIST (image task)

**Problem:** replace the A5 diffusion training objective with the CFM objective, keeping the same UNet backbone.

**Implementation tasks:**
1. Change the forward process from the VP-SDE noise schedule to linear interpolation.
2. Change the training target from `epsilon` or `x_0` prediction to velocity-field prediction `u_t = x_1 - x_0`.
3. Change sampling from DDPM/DDIM to Euler ODE integration.

**Verifiable tasks:**
- Show that with 1000 Euler steps, FID matches A5 diffusion FID.
- Show that with 10-50 Euler steps, FID stays competitive with A5 at 1000 steps.
- Visualize generated samples at 1, 5, 10, 50, 100 steps.

### 2e. (Optional, harder) Logit-normal timestep sampling ablation

Replace `t ~ U[0,1]` with `t = sigmoid(z), z ~ N(0, 1)` during training and compare training curves and sample quality at low NFE. This directly shows why SD3's timestep sampling matters.

## 3. Assessment of the draft scope

### What is correct and well-calibrated

- The CFM objective (velocity field regression on straight-ish paths) is the right central mechanism.
- Reflow is correctly identified as the path to straighter trajectories.
- The "diffusion and flow matching are two views of the same coin" connection is real and important to teach.
- Reusing A5's backbone is pedagogically sound — the only changes needed are the path definition, training target, and sampler.
- FLUX and SD3 as exemplars is correct: both are production-scale systems built on rectified flow / linear CFM.

### What is missing or under-specified

**Logit-normal timestep sampling** is absent from the draft but is one of the most practically significant contributions of SD3 (Esser et al., 2024). It should be explicitly taught, not treated as a footnote. Uniform timestep sampling systematically under-trains the perceptually important mid-noise range. The ablation (task 2e above) makes this concrete.

**OT coupling vs. independent coupling** is not mentioned in the draft. This is a first-class concept — Tong et al. (2023) showed that OT-CFM produces straighter flows than vanilla CFM even before reflow, and it is the default path in modern production systems. Students should implement both and compare.

**Mean flows (MeanFlow, Geng et al., 2025)** are absent. This is the current state-of-the-art for one-step flow generation and represents a conceptual advance beyond "straighten trajectories via reflow." The mean-velocity formulation is a new ground truth: instead of learning `v_t` and hoping integration gives the right endpoint, you directly learn `(x_1 - x_0) / 1` as the mean velocity, with a consistency constraint. A brief treatment is warranted, even if not fully implemented.

**Consistency flow matching (Yang et al., 2024)** is a related method that enforces velocity self-consistency along trajectories, converging 4.4x faster than vanilla consistency models. Not essential to implement, but worth a one-paragraph mention.

**Stochastic interpolants (Albergo & Vanden-Eijnden, 2023)** provide the most general unifying framework: they subsume diffusion models, flow matching, and Schrodinger bridges as special cases. The draft does not mention them. At minimum, a footnote connecting CFM to the stochastic interpolant framework is needed for theoretical completeness.

**The exact score-velocity relationship** should be stated explicitly: for a Gaussian path with `x_t = (1-t)x_1 + t*x_0`, the score function is `∇_x log p_t(x) ≈ (t*v_θ(x,t) - x) / (1-t)^2` (up to schedule-dependent constants). This makes the "two views of the same coin" claim precise rather than vague.

### What is outdated or mis-emphasized

**Reflow is not the dominant path to few-step generation in 2025.** The draft presents reflow as the primary mechanism for achieving few-step quality. This was accurate in 2022-2023. By 2024-2025, the field has moved toward:
- Distillation-based methods (consistency distillation, adversarial distillation, score distillation) which are generally cheaper than multiple reflow iterations.
- MeanFlow (Geng et al., 2025) which achieves one-step generation without reflow at all.
- Rectified Diffusion (ICLR 2025) which argues that trajectory straightness is not what reflow actually achieves — the key benefit is the better noise-sample coupling, not straightness per se.

Reflow should still be taught as the canonical first approach to trajectory straightening, but it should be framed as one of several few-step strategies, not the state of the art.

**"Show it matches A5 sample quality in far fewer steps"** is the right learning goal but may need to be scoped more carefully. On a 12GB GPU training from scratch on MNIST/FashionMNIST, the comparison will be noisy. It is more honest to frame it as "show that 10-step Euler with a well-trained flow model is competitive with 1000-step DDPM," which is demonstrable on small datasets.

**The framing "flow matching and diffusion are two views of the same coin"** is accurate but needs to be accompanied by a clear statement of where they differ: (a) the linear schedule is not variance-preserving, changing the effective loss weighting; (b) OT coupling is unique to flow matching; (c) the velocity parameterization enables exact log-likelihood computation via the continuous change-of-variables formula, which epsilon-prediction does not.

### Suggested reorder

1. Motivate with CNF background (why direct regression is better than simulation-based training).
2. CFM objective derivation for linear paths.
3. Implement 2D CFM with independent coupling (core).
4. OT coupling: motivation, implementation, comparison.
5. Diffusion-flow equivalence: formal statement, practical implications.
6. Logit-normal timestep sampling: motivation and ablation.
7. Reflow: the reflow procedure, implement on 2D toy, then scale to MNIST.
8. Few-step methods survey: reflow vs. distillation vs. MeanFlow (conceptual only).
9. Production systems: SD3, FLUX as case studies.

## 4. Connections to adjacent modules

### Builds on A5 (diffusion)

A5 teaches the score matching / DDPM / DDIM stack. The key intellectual bridge is: diffusion models with a VP-SDE schedule define a probability path; flow matching generalizes this to any path, and the linear path is simpler and straighter. The training objective is structurally the same (MSE on a network output given noisy input), but the target changes from `epsilon` to `velocity`. Swapping between them requires changing three things: the path equation, the training target, and the sampler. This should be made concrete by implementing both in the same codebase and switching between them with a flag.

The "two coins" teaching moment: show that `v = x_1 - x_0` under a linear schedule and `epsilon = x_0` under a VP-SDE schedule are both valid training signals for the same underlying generative process, differing only in how the network parameterizes the velocity.

### Feeds A7 (DiT)

A7 covers Diffusion Transformers. FLUX and SD3 both combine the flow matching training objective (A6) with the DiT architecture (A7). Students should know by the end of A6 that the velocity-field training objective is architecture-agnostic — the same loss works whether the backbone is a UNet (A5/A6) or a DiT (A7). SD3's MMDiT architecture adds bidirectional image-text attention, but the training loss is the same CFM + logit-normal timestep sampling introduced in A6.

### Feeds A13 (VLA action head)

pi0 (Physical Intelligence, 2024) uses a flow-matching action head: the robot action space is treated as a small-dimensional distribution, and a flow model is trained to map Gaussian noise to action trajectories. The same CFM objective and Euler sampling from A6 are applied directly, with 10 flow steps at inference enabling 50 Hz control. A13 students who have implemented flow matching from scratch in A6 can immediately understand the action head architecture.

## 5. Must-read sources

1. **Lipman et al., "Flow Matching for Generative Modeling," ICLR 2023 (arXiv:2210.02747, 2022).** The original CFM paper. Introduces the simulation-free training objective, conditional probability paths, and OT displacement interpolation. This is the primary theoretical reference.

2. **Liu, Gong & Liu, "Flow Straight and Fast: Learning to Generate and Transfer Data with Rectified Flow," ICLR 2023 (arXiv:2209.03003, 2022).** Independent derivation of linear flow matching, introduces the reflow procedure and the straightness-enables-few-step-sampling argument. InstaFlow (arXiv:2309.06380, 2023) is the follow-up showing this at SD scale.

3. **Tong et al., "Improving and Generalizing Flow-Based Generative Models with Minibatch Optimal Transport," TMLR 2024 (arXiv:2302.00482, 2023).** Introduces OT-CFM. Demonstrates that minibatch OT coupling straightens trajectories without reflow and is the default in modern production flows.

4. **Esser et al., "Scaling Rectified Flow Transformers for High-Resolution Image Synthesis," ICML 2024 (arXiv:2403.03206, 2024).** The SD3 paper. Introduces logit-normal timestep sampling, shows scaling laws for rectified flow transformers, and is the direct precursor of FLUX.

5. **Albergo & Vanden-Eijnden, "Stochastic Interpolants: A Unifying Framework for Flows and Diffusions," JMLR 2024 (arXiv:2303.08797, 2023).** The most general unifying theory. Subsumes both diffusion and flow matching as special cases of stochastic interpolants. Essential for understanding the theoretical landscape.

6. **Geng et al., "Mean Flows for One-step Generative Modeling," NeurIPS 2025 (arXiv:2505.13447, 2025).** Introduces the mean-velocity formulation, achieving one-step FID 3.43 on ImageNet 256 without distillation. Represents the current frontier of flow-based few-step generation.

7. **Dao et al., "Improving the Training of Rectified Flows," NeurIPS 2024 (arXiv:2405.20320, 2024).** Shows that one reflow iteration is sufficient and proposes U-shaped timestep distributions. Nuances the "multiple reflow iterations" narrative from the original paper.

**Omissions in the draft scope:**
- Tong et al. (OT-CFM) is not mentioned — a significant omission.
- Albergo & Vanden-Eijnden (stochastic interpolants) is not mentioned.
- Geng et al. (MeanFlow) is not mentioned.
- Esser et al. (SD3) is not mentioned by name even though it is cited as motivation.

## 6. 2024-2026 developments that change how this should be taught

### Reflow is not the end of the few-step story

The original Liu et al. (2022) paper presented 2-rectified flow + distillation as the path to one-step generation. By 2025, this picture has become more nuanced:

- **Rectified Diffusion (ICLR 2025)** argues that trajectory straightness is a side effect, not the cause, of reflow's benefits. What actually matters is the better noise-data coupling obtained by simulating the original model. This undermines the "straighten trajectories to go fast" narrative and should be acknowledged.
- **MeanFlow (NeurIPS 2025)** achieves one-step generation by modeling the average velocity directly, without any reflow. It converges stably without a curriculum (unlike consistency models) and without the computational overhead of reflow. This is now the strongest principled one-step method.
- **Consistency Flow Matching (Yang et al., arXiv:2407.02398, 2024)** combines flow matching with a consistency constraint on velocities along the same trajectory, converging 4.4x faster than consistency models and 1.7x faster than rectified flow.
- **Distillation methods** (adversarial, progressive, score distillation) remain competitive and are often preferred in production because they can be applied post-hoc to any pre-trained model without re-training.

The course framing should present reflow as the canonical pedagogical path to few-step generation, while noting that the research frontier has moved toward consistency-style and mean-velocity formulations.

### Logit-normal timestep sampling is now a standard technique

SD3 and subsequent models (FLUX, Movie Gen) all use logit-normal or similar non-uniform timestep distributions. This is no longer an obscure trick — it is a default design choice. The course should include it as a standard component, not an optional ablation.

### The diffusion-flow equivalence is now well-understood

The equivalence is rigorously documented at diffusionflow.github.io and in multiple 2023-2024 papers. The teaching can now be precise: show the algebra connecting v-prediction in DDIM to velocity-field regression in CFM, with the same cosine schedule, and demonstrate that the training losses are numerically identical up to a constant weighting. This is more valuable than a vague "two views" metaphor.

### Flow matching has largely displaced diffusion in new large-scale systems

All major text-to-image systems launched since mid-2024 use flow matching with a linear/OT path rather than a VP-SDE diffusion path: FLUX.1 (Black Forest Labs, August 2024), SD3 (Stability AI, 2024), and Movie Gen (Meta, 2024). The course framing should reflect this: flow matching is not an alternative to diffusion, it is the current default for production image generation.

### VLA action heads using flow matching

pi0 (Physical Intelligence, 2024) established flow matching as the standard action generation method in VLA robotics. The action expert runs 10 flow matching steps at inference, enabling 50 Hz control. Students completing A6 should understand that this is a direct application of the CFM objective they implemented, not a separate technique.

### Minibatch OT coupling has practical tooling

`scipy.optimize.linear_sum_assignment` and the `pot` (Python Optimal Transport) library make minibatch OT coupling straightforward to implement. The overhead is small for mini-batch sizes used in student experiments (256-512 samples). There is no excuse for not including it.
